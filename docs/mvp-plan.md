# 红米与 iPhone 电子墨水屏 MVP

确认日期：2026-10-19。目标：选图 → 编辑裁剪 → 手机本地六色抖动预览 → HTTPS 上传 → MQTT 通知 ESP → HTTPS 下载 → 刷屏及结果回报。

整体实施补充方案：[iPhone免费自测计划](ios-free-testing-plan.md)。用户已确认实施：iPhone主力自测、GitHub免费macOS构建、Ubuntu本地自动注入连接配置后签名、USB安装和续签；不采用SideStore或无线安装。先完成不依赖iPhone连接的开发、发布和构建准备，实际安装及手机闭环等用户接线后进行。

## 范围与硬件

- Flutter 共用 Android/iOS 代码；iPhone15Pro（iOS26.7.1）改为主力自测机，红米保留安卓兼容性验收，移除Mate30。使用GitHub公开仓库的macOS/Xcode编译未签名IPA，Ubuntu本地免费个人签名后通过USB安装，不要求购买本地Mac。iOS仍需实际构建、签名及实机验证。
- 个人单屏，不做账户注册、多屏、手机配网、图库、轮播或 OTA。
- ESP32-S3，16MB PSRAM、32MB Flash；GDEP073E01，800×480，六色；沿用 esp_elink_uart 的驱动、接线、Wi-Fi 与串口协议。

## 手机

- 相册选图，处理 EXIF，支持 JPEG/PNG 和系统解码 HEIC；透明像素合成白色。
- 固定 5:3 裁剪框；双指缩放、拖动、任意角度旋转，角度微调、90°按钮、重置；始终铺满裁剪框。
- 确定后生成 800×480 图像，后台 isolate 执行固定版本的颜色增强与蛇形 Burkes 六色抖动。预览由最终面板数据反解，发送使用同一份数据。
- 格式：按行扫描，每字节高半字节为左像素，黑0/白1/黄2/红3/蓝5/绿6，总长192000字节。
- HTTPS 上传、创建任务、前台轮询进度，恢复前台后继续查询。预览目标2秒，优先以iPhone15Pro测量，红米另做安卓兼容性测试。
- 自用App安装后打开即自动连接，无需输入云端地址、令牌或登录账号。公开IPA不含私有凭证，Ubuntu本地签名前自动写入现有私有连接配置，App启动时自动读取并安全保存。

## 云端

- 已验证 ssh tencent 可连接；Ubuntu 24.04、2核、约2GB内存、33GB可用盘。
- FastAPI、SQLite、本地文件、Mosquitto、Nginx、systemd；无需 Docker/Redis/对象存储。
- 公网IP、私有CA、HTTPS443/MQTTS8883；App显式信任CA，ESP校时后验证证书。个人App令牌、设备下载凭据、独立MQTT账号与ACL，不公开秘密。
- GET /v1/device；POST /v1/images；POST /v1/refresh-jobs（幂等键）；GET /v1/refresh-jobs/{id}；GET /v1/device/images/{id}。
- 校验长度、色码和SHA-256；单设备单任务，忙或离线不排队。MQTT QoS1，命令不retain，有任务ID和有效期；状态含创建、下发、下载、刷新、完成、失败、结果待确认。
- 仅设备回报对应任务驱动成功才算完成。文件保留7天，保护执行中数据。

## 固件与故障处理

- MVP内独立固件，串口和网络共享忙锁；HTTPS图像进PSRAM，校验后才刷屏。
- 失败整图下载最多3次，无断点续传；刷新不自动重试；保留BUSY超时。
- NVS记录任务与结果，重复MQTT不重复刷新。重启遇到未完成任务报告结果待确认，不自动重刷。
- Wi-Fi/MQTT自动重连、心跳、遗嘱离线；factory应用分区4MiB，不做OTA，不把换图内容写Flash。
